# 그룹웨어 레거시 현대화

> 380개 JSP 페이지 규모의 사내 그룹웨어(전자결재·급여·달력·게시판)를 **운영을 멈추지 않고**
> UI 전면 개편과 보안·안정성 개선까지 함께 진행했습니다.
> 기존 마크업은 그대로 두고 그 위에 스타일 레이어를 얹는 방식으로 회귀 위험을 줄였습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.01 ~ 02 |
| 역할 | 프로젝트 주관 · 1인 개발 (분석 · 설계 · 구현 · 현업 의견 수렴 · 반영) |
| 스택 | Java 8 · JSP · iBATIS · jQuery · MS SQL Server 2014 · Tomcat |
| 규모 | JSP 380페이지 · 전자결재 양식 30종 |

---

## 1. 배경

전자결재·급여·달력·게시판 등 전 모듈의 UI/UX를 현대화하면서, 쿼리 일부가 문자열 치환으로 조립돼 있던 SQL Injection 위험도 함께 정리했습니다.
전 직원이 매일 쓰는 시스템이어서 **기존 기능을 깨지 않는 것**이 첫 번째 조건이었습니다.

## 2. 설계 원칙

**기존 마크업을 보존한다.** JSP 구조를 고치지 않고 override 레이어(CSS)를 얹어 380개 페이지를 리디자인 → 화면별 로직 회귀 위험 최소화

**운영 환경을 바꾸지 않는다.** Java 8 · MS SQL Server 2014 호환을 유지하는 범위에서만 변경

## 3. 구현

### 3-1. 유지보수 · 보안

- iBATIS 쿼리의 문자열 치환(`$param$`)을 파라미터 바인딩(`#param#`)으로 전환 → SQL Injection 제거, SQL 최적화
- 세션 관리 강화: 중첩 iframe 안의 사용자 활동 감지, keepAlive 튜닝
- 급여 모듈 NPE · null 처리 보완

### 3-2. 화면 · 프론트

- CSS 토큰 시스템 신규 구축, 라이트/다크 듀얼 테마 도입 (전자결재 양식 30종 포함)
- 팝업 UI 공통화, 아이콘 · date picker 체계 정리
- 달력 모듈 FullCalendar 6 마이그레이션 (다크모드 · 렌더링 런타임 이슈 해결)
- 조직도에서 바로 메일을 보내는 원클릭 메일 기능 개발

### 3-3. 개편 이후 대응

대규모 UI 개편 초기에 사용자 불만 문의가 있었고, 요구를 수집해 순차 반영했습니다.

## 4. 결과

- 조직도 메일 발송 4단계 → 1단계 (약 75% 감소)
- 개편 관련 불만 문의 2주 만에 약 90% 감소
- 기존 마크업 보존으로 전자결재 · 달력 등 주요 모듈을 서비스 중단 없이 전환
