# Delphi ERP 자원관리 자동화 — 바코드 · 이미지 · PPT

> 전 직장 Delphi ERP의 자원관리 모듈에서 담당자가 손으로 하던 세 가지 작업을
> **바코드 출력 → FTP 이미지 관리 → PowerPoint 자동 생성** 순으로 자동화했습니다.
> 세 기능이 서로 기반이 되어 PPT 자동 생성은 앞서 만든 이미지·코드 체계를 그대로 재사용합니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2023.12 ~ 2024.06 (기능 3건 순차 개발) |
| 역할 | 전체 주관 — 설계 · 개발 · 현업 테스트 · 적용 |
| 스택 | Delphi · DataSnap(Client-Server) · FTP · MS Office 자동화 · 네트워크 프린터 |

---

## 1. 바코드 출력 (2023.12)

**문제**: 자원 코드를 담당자가 눈으로 조회하고 손으로 입력 → 오기입과 조회 시간

- 바코드 생성 컴포넌트 추가, 리스트 데이터별 바코드 위치를 지정해 출력 포맷 표준화
- 바코드 전용 네트워크 프린터 연결 → 여러 담당자가 각자 자리에서 즉시 출력

**성과**: 수기 조회·입력 → 스캔 기반 관리로 전환, 수기 입력 오류 대부분 제거

## 2. FTP 이미지 업로드 · 다운로드 · 삭제 (2024.03 ~ 04)

**문제**: 자원 이미지가 담당자 PC에 흩어져 있어 공유·관리 불가

- 이미지 메타 테이블 신설, Client–DataSnap 연동으로 입력·조회
- 입력 화면에서 지정 FTP 경로로 업로드, 다운로드·삭제 버튼으로 화면 내 일괄 처리

**성과**: 이미지 자산을 FTP 서버로 중앙 일원화, 파일 수기 관리 과정 제거

## 3. PowerPoint 자동 생성 (2024.05 ~ 06)

**문제**: 자원 목록을 PPT로 만드는 데 1건당 1시간 이상, 수기 편집 중 누락·오기입

- 별도 테스트 프로젝트에서 PowerPoint 이벤트 처리 검증 후 현업 화면에 적용
- DataSnap으로 출력 대상 리스트 조회 → 레코드 수만큼 슬라이드 생성
- FTP에서 코드별 이미지를 가져와 각 슬라이드에 배치, 코드 정보 텍스트 출력
- 진행률 바로 대량 변환 상태 실시간 표시

**성과**: 1건당 약 1시간 → 1분 내외 (약 98% 단축), 수기 편집 누락·오기입 제거
