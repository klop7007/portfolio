# 그룹웨어 업무 화면 3건 — 장비 예약 · 거래처 평가 · 근태 캘린더

> 사내 그룹웨어(JSP + MS SQL Server)에서 현업 요청을 받아 단독으로 설계·개발한 업무 화면 3건.
> 종이·엑셀·구두로 돌던 프로세스를 전자결재 데이터와 연결해 화면으로 옮겼습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2020.07 ~ 2023.04 (3건 순차) |
| 역할 | 각 건 프로젝트 주관 · 단독 개발 · 현업 협의 · 적용 |
| 스택 | JSP · JavaScript/jQuery · MS SQL Server · fullcalendar |

---

## 1. 장비 예약 시스템 (2020.07 ~ 10)

**문제**: 공용 장비를 구두·메신저로 예약해 같은 시간에 두 팀이 겹치는 일이 반복

- 신청 → 승인/반려 → 반납 프로세스를 예약 팝업 하나로 구성
- 예약 현황 테이블 신설, 장비 정보 테이블과 join해 이력 저장·조회
- fullcalendar로 장비별 예약 현황을 달력에 표시 → 빈 시간을 보고 신청

**성과**: 장비 1건마다 승인·반려를 알림 팝업으로 즉시 처리 → 장비 사용 충돌 제거

## 2. 거래처 평가 등록 (2022.11 ~ 12)

**문제**: 협력업체 평가를 종이 양식으로 받아 취합·집계를 담당자가 수작업

- 거래처 유형(상품/서비스/용역)별 평가 항목이 달라 테이블 3개로 분리
- 체크박스 채점 → JavaScript로 실시간 합계
- 중간 결재자가 평가 단계에서 점수를 수정할 수 있도록 결재 흐름에 편집 이벤트 연결

**성과**: 평가 전산화 후 첫 분기(2023 1Q)에 18건이 시스템으로 완료돼 프로세스 정착

## 3. 근태 일정 캘린더 (2023.03 ~ 04)

**문제**: 근태·휴가·출장이 각각 다른 결재 문서라 부서원이 오늘 누가 자리에 없는지 한눈에 알 수 없음

- 결재 완료된 근태·휴가·출장 신청서 3종을 SQL로 집계해 개인별 일정으로 변환
- fullcalendar로 한 달력에 표시, 부서 선택 팝업으로 타 부서 일정 조회
- 부서 미선택 시 본인 부서가 기본값

**성과**: 결재 문서 3종을 열어보던 것 → 달력 한 화면. 2026년 근태 DX에서 이 캘린더에 유연근무 시간 표기를 추가해 계속 사용 중
