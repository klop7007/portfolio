# ERP 연동 화면 2건 — 자금일보 · ERP–WMS 비교

> ERP에 갇혀 있던 데이터를 다른 시스템에서 바로 보게 만든 연동 화면 2건.
> 하나는 ERP → 그룹웨어, 하나는 ERP ↔ WMS(MySQL) 방향으로, 담당자가 시스템을 오가며 대조하던 일을 없앴습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2020.10 ~ 2021.01 (2건 순차) |
| 역할 | 화면 설계 · SQL 작성 · 데이터 연동 · 적용 |
| 스택 | JSP · JavaScript · MS SQL Server · MySQL(링크서버/OPENQUERY) · Visual Studio |

---

## 1. 자금일보(CMS) 그룹웨어 화면 (2020.10 ~ 11)

**문제**: 자금일보는 ERP 안에만 있어 재무팀 외에는 ERP에 접속해야 볼 수 있고, 마감됐는지도 ERP를 열어야 확인 가능

- ERP 자금일보 데이터를 그룹웨어 JSP 화면으로 가져오는 조회·파라미터 연동
- ERP에서 마감 체크 시 그룹웨어 화면에 마감 여부가 표시되도록 JavaScript 분기
- 일자·조건 파라미터로 원하는 날짜의 일보 조회

**성과**: ERP 접속 없이 그룹웨어에서 자금 현황·마감 여부 확인 → 재무팀의 "오늘 마감했나요?" 문의 응대 제거

## 2. ERP–WMS 발주 비교 화면 (2020.12 ~ 2021.01)

**문제**: 발주는 ERP(MS SQL), 창고 작업 상태·재고는 WMS 웹포털(MySQL)에 따로 있어 생산 담당자가 두 시스템을 오가며 대조

- ERP에 구매발주 비교 Form 신설 (Visual Studio)
- MS SQL에서 MySQL을 링크서버로 연결, OPENQUERY로 WMS 작업 상태·재고를 가져와 ERP 발주 상세와 조인
- 발주 건별 ERP 수량 vs WMS 입고·재고를 한 그리드에 표시

**성과**: WMS 포털 별도 로그인·수기 대조 제거 → ERP 한 화면에서 발주–입고–재고 확인
