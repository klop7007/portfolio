# 전사 업무관리 시스템 — M/M 가동률 관리

> 팀장들이 매월 엑셀로 집계하던 M/M 가동률을 시스템으로 옮긴 사내 업무관리 시스템.
> 공동 개발 프로젝트이며, **M/M 가동률 관리 기능과 레거시 그룹웨어 연동**을 담당했습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.03 ~ 04 |
| 역할 | 공동 개발 (기여도 약 30%) — M/M 가동률 관리 개발 · 레거시 그룹웨어 연동 |
| 스택 | PostgreSQL · MS SQL Server · JWT |
| 규모 | 4개 계열사 약 100명 사용 |

---

## 1. 배경

과제별 투입 인력(M/M)을 팀장 18명이 매월 엑셀로 따로 집계했습니다.
인사 · 조직 정보는 그룹웨어에 이미 있는데도 집계할 때 같은 정보를 다시 입력해야 했습니다.

## 2. 구현

### 2-1. M/M 가동률 관리

- 전략과제 × 팀원 매트릭스 기반으로 조직 계층별 가동률 조회 · 집계
- JWT 기반 조직 범위 적용: 관리자 · 그룹리더 · 일반 사용자별 조회 권한 분리
- 그룹리더용 하위 조직 집계 대시보드

### 2-2. 집계 배치

- 일별 데이터를 월별로 다시 집계하는 스케줄러
- `ON CONFLICT` 기반 UPSERT로 멱등 처리, 전월 재처리 배치 포함

### 2-3. 레거시 그룹웨어 연동

- 그룹웨어(MS SQL Server)의 인사 · 조직 데이터를 자사 DB(PostgreSQL)로 단방향 동기화

## 3. 결과

- 팀장 18명의 월별 수기 엑셀 집계를 대시보드로 전환, 연 약 864시간 절감
- 4개 계열사 인사 · 조직 데이터 자동 동기화로 이중 입력 제거, 조직도 최신 상태 유지
- 멱등 UPSERT로 월별 재집계 시 중복 · 누락 방지
