## 1. 문서 통합 검색 튜닝 (2021.11 ~ 12)

**문제**: 관리자 등급에 따라 볼 수 있는 문서가 달라 권한 조건이 한 SELECT에 얽혀 있었고, 통합 검색에 10초 이상 소요

- 단일 SELECT를 저장 프로시저로 전환
- 로그인 사용자의 관리자 등급을 먼저 판별해 조회 조건 분리
- 조회 대상을 임시 테이블에 적재한 뒤, 등급별로 보이면 안 되는 문서를 제외

**성과**: 통합 검색 10초 이상 → 약 1초

## 2. 휴가 결재라인 자동 지정 (2023.01 ~ 02)

**문제**: 휴가를 올릴 때마다 사용자가 결재라인을 직접 지정해야 했고, 부서 이동 · 신규 입사가 있으면 결재라인 정보도 따로 맞춰야 했음

- JavaScript · jQuery로 저장 버튼 · 근태 코드 변경 이벤트 처리
- ERP에 신규 입사자 등록 시 부서 코드 기준으로 전결자를 자동 지정하는 프로시저
- ERP에서 부서 변경 시 전결자 정보를 자동 갱신하는 프로시저

**성과**: 휴가만 선택하면 결재 상신, 조직 변경은 프로시저의 부서 코드만 수정하면 대응

## 3. 사내 익명 게시판 (2021.02 ~ 03)

**목적**: 직원 간 소통과 건의를 위한 익명 게시판

- 게시물 · 댓글 · 대댓글 작성자를 익명 또는 닉네임으로 처리해 저장
- ERP 관리자 정보와 연동해 관리자에게만 공지 설정 표시

**성과**: 익명 건의 창구 마련, 경영지원팀 연간 평균 10건 이상 처리

## 4. ERP 자격사항 등록 화면 (2022.10 ~ 11)

**목적**: 임직원 개인별 자격사항 관리 전산화

- ERP 자격사항 등록 Form 개발 (Visual Studio)
- 관리자만 전 직원을 조회하도록 권한 제어
- FTP 연동 드래그 앤 드롭 파일 업로드

**성과**: 자격사항 전산화, 2023년 1분기 업로드율 70%
