# 그룹웨어 솔루션 고객사 커스터마이징

> 그룹웨어 패키지를 납품받은 고객사의 요구에 맞춰 기능을 고치고 운영을 지원했습니다.
> Spring 기반 계층 구조(VO · DAO · Service)와 화면 · SQL을 함께 수정하는 커스터마이징이 주 업무였습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2018.02 ~ 2020.06 |
| 역할 | 담당 고객사 커스터마이징 개발 · 기술지원 · 패키지 유지보수 |
| 스택 | Java · Spring Framework · eGovFrame · MyBatis · Oracle · JSP · JavaScript/jQuery |
| 운영 환경 | Linux · Tomcat · JEUS · Git · SVN · Jenkins |

---

## 1. 커스터마이징 개발

- 고객사 요구에 맞춰 VO · DAO · Service · ServiceImpl 계층과 JSP · JavaScript 화면, SQL 수정
- **계정 자동 잠금 (2018.05, 단독 개발)**: 로그인 이력에 실패 횟수를 기록해 5회 실패 시 계정 잠금, 로그인 성공 시 횟수 초기화

## 2. 기술지원 · 유지보수

- 분기별 문서 리스트를 SQL로 추출, HTML이 깨진 문서 복구
- 구 패키지 → 신 패키지 전환 시 문서 이관
- 고객사 서버 월 정기 점검으로 용량 확보 · 오류 예방
- Git · SVN · Jenkins로 변경 이력 관리

## 3. 결과

- 정기 관리로 월별 오류 건수 감소
- 고객사의 시스템 고도화 추가 요청으로 연결
