# 은행 비고시환율 자동 수집 · ERP 연동

> 고시환율 피드에 없는 비고시통화 환율을 담당자가 매일 은행 사이트에서 찾아 ERP에 손으로 넣던 일을,
> **은행 웹 수집 → 프로시저 적재 → 일 배치**로 자동화했습니다.
> 기존 고시환율 흐름은 건드리지 않고 별도 배치로 붙였습니다.

| 항목 | 내용 |
|---|---|
| 기간 | 2026.07 ~ 08 |
| 역할 | 1인 — 분석 · 개발 · 배포 · 운영 |
| 스택 | PowerShell · MS SQL Server(프로시저 · MERGE) · SQL Agent |

---

## 1. 배경

ERP는 고시환율을 자동으로 받아 오지만, 비고시통화는 피드에 없어 담당자가 하루 한 번 은행 사이트를 조회해 직접 입력했습니다.
사람이 옮겨 적다 보니 입력 누락과 대조 시간이 계속 발생했습니다.

## 2. 설계 원칙

**기존 흐름을 건드리지 않는다.** 잘 돌아가는 고시환율 처리에 손대지 않고, 독립된 배치로 구성

**몇 번 실행해도 결과가 같다.** MERGE로 적재해 재실행·중복 실행에도 데이터가 어긋나지 않게 설계

**자격증명을 남기지 않는다.** Windows 통합 인증과 최소 권한 계정으로 평문 자격증명 제거

## 3. 구현

```
은행 비고시환율 페이지 ──▶ PowerShell 수집(POST · HTML 파싱, TLS 1.2)
                              └─▶ 적재 프로시저(MERGE) ──▶ ERP 환율 테이블
                                   SQL Agent 독립 Job (일 1회)
```

- 은행 페이지 요청 구조 분석 후 POST 요청 · HTML 파싱으로 환율 수집
- 적재 프로시저에서 MERGE로 멱등 적재
- 수집 실패 시 전일 환율을 쓰는 fallback 적용 → 일시 장애에도 환율 공백 없음

## 4. 결과

- 일 1회 수동 조회 · 입력 100% 자동화
- 은행 사이트 표기값과 ERP 반영값 100% 일치, 환율 검증 · 대조 시간 단축
- 기존 고시환율 업무에 영향 없이 운영
